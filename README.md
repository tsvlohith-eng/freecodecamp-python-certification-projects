# 🐍 freeCodeCamp Python Certification Projects

This repository contains the 5 certification projects completed for the freeCodeCamp **Python Certification**, covering data structures, OOP, file handling, and recursion.

---

## 📁 Projects

1. **User Configuration Manager** (`user-configuration-manager.py`)
   - Handles configurations using dictionaries, sets, and error handling.
2. **Budget App** (`budget-app.py`)
   - Expense tracker with visual spending charts using OOP.
3. **Polygon Area Calculator** (`polygon-area-calculator.py`)
   - Rectangle and Square calculations demonstrating inheritance.
4. **Hash Table** (`HashTable.py`)
   - Hash table implementation with collision handling.
5. **Tower of Hanoi Algorithm** (`Towers of Hanoi.py`)
   - Algorithmic puzzle solver using recursion.
